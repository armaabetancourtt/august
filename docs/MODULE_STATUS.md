# Module Status

AUGUST deliberately distinguishes **implemented foundation**, **benchmark-ready** and **future** work.

| Module | Status |
|---|---|
| Macroeconomic intelligence | synthetic engine + public adapters foundation |
| Time-series forecasting | rolling-origin evaluator + naive baselines |
| Real-estate intelligence | transparent valuation baseline |
| Scenario engine | 10k-path Monte Carlo implementation |
| Fraud detection | synthetic generator + temporal logistic baseline |
| Fraud explainability | structured decision evidence; SHAP future |
| Graph fraud | graph construction / suspicious components |
| Customer segmentation | clustering-quality evaluation primitive |
| Propensity | probability calibration report |
| Causal inference | DiD baseline |
| A/B testing | power + two-proportion inference |
| Marketing mix | adstock + saturation transforms |
| Anomaly detection | robust-z baseline; advanced detectors future |
| Root cause | exact Shapley revenue decomposition |
| NLP intelligence | TF-IDF + clustering baseline |
| GenAI analyst | deterministic grounding + retrieval baseline |
| Advanced statistics | bootstrap uncertainty utility |
| Model validation | model cards + temporal strategy patterns |
| Model drift | PSI / KS / JS / Wasserstein |
| MLOps | serialization + metadata registry, API, Docker, CI |

A status row is not evidence of model quality. Metrics are only published after a reproducible benchmark.
